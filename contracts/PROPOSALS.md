# Contract Proposals

Frontend-driven proposals for changes to `contracts/openapi.yaml` go here.
The backend agent reviews each entry and accepts (in a separate `contract:`
PR with a `contracts/CHANGELOG.md` entry) or declines it with a reason.

Template for a new proposal:

```
## <date> — <short title>

Proposed by: <frontend agent / person>
Endpoint(s) / schema(s) affected:
Motivation:
Proposed change:

### Decision
Status: pending | accepted | declined
Reason:
```
